# Le Carnet — Blog React

Exercice React : liste d'articles avec recherche et filtres par catégories.

## Fonctionnalités
- Articles stockés dans `src/data/articles.js` et affichés dans `App.jsx`
- Recherche en direct sur le titre, les mots clés, les catégories et le texte (insensible aux accents et à la casse)
- Filtres par tags (catégories), cumulables, cliquables aussi depuis les cartes
- 26 articles, mise en page responsive avec Tailwind CSS
- Images chargées depuis un CDN (picsum.photos)

## Lancer le projet
```bash
npm install
npm run dev
```
